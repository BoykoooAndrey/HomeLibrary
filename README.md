# HomeLibrary

Веб-приложение «Домашняя библиотека».

## Возможности

- просмотр книг в виде карточек и списка;
- добавление, редактирование и удаление книг;
- добавление авторов;
- поддержка нескольких авторов у одной книги;
- хранение оглавления книги в формате XML;
- форматирование оглавления с помощью HTML-редактора;
- поиск по названию книги, автору и оглавлению.

## Технологии

- .NET 8
- ASP.NET Core Web API
- Dapper
- MS SQL Server 2022
- HTML / CSS / JavaScript
- Docker
- Docker Compose

## Структура приложения

Backend приложения разделён на слои:

`Controller → Service → Repository → Database`

- `Controller` — HTTP API;
- `Service` — бизнес-логика и валидация;
- `Repository` — работа с базой данных через Dapper;
- `Database` — SQL-скрипты создания и начального заполнения базы данных.

Для добавления, редактирования и удаления книг используются хранимые процедуры MS SQL Server.

Для обработки необработанных исключений используется глобальный обработчик исключений.

## База данных

Основные таблицы:

- `Books` — книги;
- `Authors` — авторы;
- `BookAuthors` — связь many-to-many между книгами и авторами.

Оглавление книги хранится в поле типа `XML`.

SQL-скрипты находятся в каталоге `Database`:

1. `01_CreateDatabase.sql` — создание базы данных;
2. `02_CreateTables.sql` — создание таблиц;
3. `03_CreateTypes.sql` — создание пользовательских типов;
4. `04_CreateProcedures.sql` — создание хранимых процедур;
5. `05_SeedData.sql` — добавление демонстрационных данных.

SQL-скрипты выполняются автоматически при первом запуске Docker Compose. Ручная инициализация базы данных не требуется.

## Запуск

Для запуска необходим Docker Desktop.

Клонировать репозиторий и перейти в каталог проекта:

```bash
git clone <repository-url>
cd HomeLibrary
```

Собрать и запустить приложение:

```bash
docker compose up -d --build
```

Docker Compose автоматически:

- запускает MS SQL Server;
- ожидает готовности SQL Server;
- создаёт и инициализирует базу данных;
- добавляет демонстрационных авторов и книги;
- собирает и запускает ASP.NET Core приложение.

После запуска приложение доступно по адресу:

```text
http://localhost:8080
```

Проверить состояние контейнеров:

```bash
docker compose ps -a
```

При успешном запуске контейнер `homelibrary-mssql-init` завершится с кодом `0`. Это штатное поведение: контейнер используется однократно для инициализации базы данных.

Логи инициализации базы данных:

```bash
docker compose logs mssql-init
```

## Остановка

Остановить приложение:

```bash
docker compose down
```

Остановить приложение и удалить данные SQL Server:

```bash
docker compose down -v
```

После удаления volume следующий запуск создаст и заполнит базу данных заново.

## Конфигурация

Для упрощения проверки тестового проекта параметры подключения к локальному контейнеру SQL Server заданы непосредственно в конфигурации проекта.

В production-среде учётные данные следует передавать через переменные окружения или специализированное хранилище секретов.
